Sobre o Estúdio

O Estúdio Friedlander é um espaço criativo interativo desenvolvido como parte desta exposição dedicada à designer Elizabeth Friedlander.

Os visitantes podem se inspirar na exposição para criarem os seus próprios designs modulares e observar como elementos individuais se combinam para formar composições repetidas maiores.

Como Usar

  • Selecione uma ferramenta (Lápis, Linha, Retângulo, Triângulo ou Círculo) e escolha a cor do pincel na barra superior.
  • Desenhe na tela para criar seu padrão unitário básico. Ative o Modo Borracha para refinar seu design.
  • Use a Guia Grade para alinhar suas geometries perfeitamente.
  • Clique em Visualizar Padrão para inspecionar a repetição contínua em escala.

Pronto para Produção

Prepare seu design para impressão selecionando a resolução desejada e clique em Exportar Padrão para salvar um PNG contínuo de alta qualidade.
